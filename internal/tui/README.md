# TUI

```bash
./treehole
TREEHOLE_THEME=dark ./treehole        # dark / light / auto
./treehole --tui-capture-dir ./.out   # 保存屏幕快照，便于调试
```

## 页面

`Tab` 切换页面：

- **同步**：管理后台采集任务。`n` 新建、`Enter` 编辑参数、`s` 启停、`x` 删除、`L` 看日志、`r` 刷新。
- **帖子**：浏览、搜索、标签筛选、看评论；在线模式可点赞/关注/发帖/评论。`Esc` 清除搜索和筛选。
- **课表**：课程安排。
- **成绩**：成绩与 GPA。

`h` 查看当前页面快捷键，`Ctrl+Q` 退出。

## 数据模式

- **在线模式**：直接调用原站 API，可读可写。
- **离线模式**：只读本地数据库。

登录失效时可选择重新登录或进入离线模式；网络不可用时提示进入离线模式。

## 搜索

离线模式下搜索框支持布尔查询，在线模式的语法和原站一致（也就是不支持复杂查询）。
